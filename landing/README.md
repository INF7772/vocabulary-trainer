# Vocabulary Trainer landing page

This is a dependency-free static site. Serve the `landing` directory from any
HTTPS static host. The screenshots are regenerated from the real application:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
npm run capture:presentation
```

Before a public release, replace the disabled release and source links in
`index.html` with the final GitHub URLs.
