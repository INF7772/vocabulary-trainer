# Распространение Vocabulary Trainer

## Готовая Windows-версия

Для пользователей распространяется архив `Vocabulary-Trainer-Windows-x64-<version>.zip`.

Пользователь должен:

1. полностью распаковать архив;
2. сохранить всю папку `Vocabulary Trainer` вместе;
3. запустить `Vocabulary Trainer.exe`.

Нельзя распространять только один файл `Vocabulary Trainer.exe` из папки `win-unpacked`: ему нужны соседние `resources`, `locales`, DLL и остальные файлы Electron.

Папка `Vocabulary Trainer Data` никогда не включается в публичный архив. Она создаётся рядом с приложением при первом запуске и содержит личные уроки, прогресс и настройки конкретного пользователя.

Однофайловый `Vocabulary-Trainer-<version>-portable.exe` также можно раздавать, но он медленнее запускается, потому что при каждом старте распаковывает Electron. Необязательные голосовые и переводческие модели в EXE не входят. ZIP обычной распакованной версии предпочтительнее для постоянного использования.

## Архив исходного проекта

`Vocabulary-Trainer-Source-<version>.zip` содержит исходники, тесты, документацию и Electron-оболочку. В него намеренно не входят:

- `node_modules`;
- `dist` и готовые release-каталоги;
- пользовательские `Vocabulary Trainer Data`;
- отчёты и временные результаты тестов;
- незавершённые старые сборки.
- необязательные голосовые и переводческие модели, включая тяжёлые тестовые voice assets.

После распаковки исходников зависимости восстанавливаются командой `npm ci`. Затем доступны `npm run build` и `npm run desktop:build`.

## Проверка скачивания

Файл `SHA256SUMS.txt` содержит контрольные суммы обоих архивов. В PowerShell архив можно проверить командой:

```powershell
Get-FileHash .\Vocabulary-Trainer-Windows-x64-0.3.0.zip -Algorithm SHA256
```

Полученная сумма должна совпасть со строкой в `SHA256SUMS.txt`.

## Публичная публикация

Текущая сборка не подписана сертификатом разработчика. Windows SmartScreen может показать предупреждение о неизвестном издателе. Для более профессионального распространения следует получить сертификат code signing, подписывать EXE и публиковать архив или установщик через HTTPS.

Перед широкой или коммерческой публикацией отдельно проверьте условия лицензий Electron, npm-зависимостей и загружаемых моделей. Это организационная проверка распространения, а не изменение работы приложения.

## Повторное создание архивов

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-distribution.ps1
```

Готовые файлы записываются в `distribution`.
