# Project status

Updated: 2026-10-08

## Completed

- Version 0.8.7 rebuilds image discovery around exact Card meaning, exact target and target-language context, followed by a concise beginner flashcard/educational-illustration refinement. The restrictive Google clip-art filter and competing exact SEO phrases are removed so textbook diagrams and real teaching cards remain eligible.
- Handwriting comparison now accepts recognizable approximate forms instead of expecting mouse, pen or touch input to reproduce the reference typeface. Coarser structural matching and wider local tolerance preserve rejection of incomplete and differently oriented shapes, and the learner-facing hint now states that individual handwriting is expected.
- Version 0.8.6 prevents duplicate visible choice answers, including the shared `o` reading of katakana `オ/ヲ`. Choice text is normalized before deduplication, and resuming an older Learn session repairs an already-saved question that contains equivalent answers.
- Version 0.8.5 reduces guided symbol handwriting in Learn to the normal two-click path: “Check answer” applies the automatic comparison, an optional control can correct it in either direction, and “Next question” records the selected result while advancing immediately.
- Version 0.8.4 labels the guided symbol-handwriting action in Learn as “Check answer”; assessment modes retain “Show answer” because their reference remains hidden until that action.
- Version 0.8.3 changes Card image discovery from real-life photography to child-friendly picture-dictionary and vocabulary-card illustrations. The generated Google Images query is shorter, no longer contains the misleading `"real life"` phrase or a long chain of exclusions, and uses the illustration/clip-art result filter; an explicitly requested photo style remains untouched.
- Version 0.8.2 keeps Japanese application-voice model initialization and inference off the renderer thread, so background Lesson speech preparation no longer freezes the interface. Symbol Lesson creation is now a four-step flow that skips translation-language selection and translation entry, uses a compatible internal cue automatically, and describes the mode as generic symbol handwriting rather than Japanese-specific kana practice.
- Version 0.8.1 packages the improved image search, stricter handwriting comparison, Learn-only tracing guide, dedicated handwriting practice, ambiguous-reading handling, and correction after “I do not know”.
- Learn can now show or hide a tracing outline during symbol handwriting, while Today, custom practice and dedicated Handwriting practice remain unguided tests. Identical readings such as `じ/ぢ → ji` and `ず/づ → zu` no longer create impossible reverse questions: choices use the solvable direction and drawings accept every matching glyph. “I answered correctly” is available after “I do not know” across Learn, Quick Choice, Practice Builder, Chaos and Today without double-counting the completed attempt.
- Handwriting comparison now requires contour coverage, spatial structure and proportions in addition to tolerant distance, preventing a single matching fragment from passing as the full sign. Symbol Lessons expose a dedicated shuffled Handwriting practice route whose explicit learner-confirmed results update global Card statistics without changing Learn or SRS progress.
- Image search now combines the Card meaning with its target-language word, favors real-life photographs, and removes common poster, cover, logo, and wallpaper results while keeping the query editable for a different visual interpretation.
- The Home screen now centers on a live “Today” queue: due FSRS reviews, an independent count of manually difficult Cards, dynamically limited new material, a time estimate, and ordered Lesson progress. Review uses Again/Hard/Good/Easy only after the learner attempts recall and reveals the answer.
- Learned Cards graduate into one global FSRS state per Card. Schema version 9 migrates existing Learned Cards as due, stores review history, preserves manual difficult markers independently, and includes scheduling data in full backups. The daily new-card maximum is configurable; review loads of 30+ reduce new material and 50+ pause it.

- Local-first React/TypeScript/Vite/Tailwind PWA with routing, i18n, Dexie/IndexedDB, unit/component/E2E tooling, themes, responsive layouts, offline app shell, and static production output.
- The canonical ten-language registry (`de`, `en`, `es`, `fr`, `it`, `ja`, `ko`, `ru`, `uk`, `zh`) now drives complete UI catalogs, localized dynamic language names, and Electron locale packaging. Fresh settings detect any supported OS locale and otherwise use English; saved interface language remains independent from Lesson languages and is preserved.
- Global reusable Cards, many-to-many Lesson membership, per-Lesson progress, global statistics, serialized Learn sessions, versioned migrations, safe Lesson deletion, schema-v6 machine-local filesystem handles, and the schema-v7 Japanese-reading preference migration.
- Framework-independent Learn, typing/IME, statistics, Quick Choice, and Chaos engines. Learn batches, dirty/remedial behavior, delayed retries, Give up, confusion penalties, timing, and exact matching remain outside React.
- Learn and Quick Choice keep a completed answer visible until explicit Next/Enter. Audio and persistence do not block navigation. When alternatives exist, the engines avoid consecutive completed questions for the same Card; repeated mistakes on one question create only one delayed retry.
- Restart Session now atomically clears Lesson-specific Learned/temporary state, removes older sessions, and queues every Lesson Card again while preserving global Card statistics.
- Learn, Quick Choice, and Chaos now have verified cumulative global Card statistics. Lesson detail shows completed-question counts and provides confirmed reset actions for one Card or all Cards in the Lesson without changing learned progress; shared-Card impact is stated before a Lesson-wide reset.
- Learn freezes its visible timer at answer completion, typing Enter cannot also advance the completed question, and Learn/Quick Choice show working `1`–`4` keyboard badges while ignoring editable fields and modifier shortcuts. Oversized active question panels scale to the remaining viewport height so feedback and controls stay visible without required scrolling.
- Practice Builder combines one or more same-target-language Lessons without duplicating shared Cards. It provides seven presets, seven Card filters, four orderings, finite/endless lengths, image/audio controls, and five formats: meaning/image choice, reverse choice, audio choice, audio typing, and meaning/image typing. Its answers update the same cumulative statistics but never alter Learn progress.
- Manual selection in Practice Builder spans several Lessons and can save the selected global Cards as a normal permanent Lesson. `lastErrorAt` is captured by the shared statistics engine so recent-error filtering works across every practice mode.
- Multiple translations render together in Learn, Quick Choice, and Chaos. Users select one non-empty visible set; the old active-language field is internal compatibility data and has no separate control.
- Lesson creation is a six-step flow with a searchable target-language combobox, direct translation-language rows, a tabbed original/translation table, validated bulk paste, per-word automatic translation, and bulk automatic translation that preserves manual values.
- Version 0.3.4 fixes Lesson creation when a new Lesson reuses a global Card from an earlier Lesson: the enclosing transaction now includes generated-audio cache updates, failures are visible instead of silent, and successful creation opens the Lesson before optional speech preparation continues with progress on the detail screen.
- Desktop automatic translation uses a reusable local `TranslationProvider` and one downloadable, pinned M2M100 package rather than Browser Translator API. Every direction between the ten canonical languages is available through the same installed model; model-host access is disabled during inference. Version 0.3.1 moved the model's WASM initialization and inference off the renderer main thread and uses bounded batches, preventing Auto translate from freezing the desktop window. Version 0.3.2 added batch/load timeouts and real generation interruption so invalid input cannot leave an endless translation state. Version 0.3.3 uses short input-aware greedy generation, repetition controls, and target-script cleanup to prevent multilingual tails and repeated hallucinations in short vocabulary.
- Japanese kana study symbols and contracted syllables now receive immediate local Hepburn readings (`あ → a`, `し → shi`, `きゃ → kya`) without requiring or starting the translation model. Lesson generation fills missing readings even when Auto translate was skipped, and opening an older affected Lesson repairs missing selected translations without replacing manual values. Longer kana words continue through semantic translation rather than being mistaken for alphabet Cards.

Learn Stage 3, Today review, and Practice Builder typing formats automatically use large font-rendered hiragana/katakana choices; ordinary vocabulary keeps strict typing. Drawing remains a separate future mode until strokes can be judged reliably.
- Japanese kana vocabulary accepts exact Hepburn romaji as well as the exact Japanese target in Learn, Today, and Practice Builder. The prompt states that `ji` covers `じ/ぢ` and `zu` covers `ず/づ`; the revealed answer still teaches the real spelling. Non-Japanese typing remains unchanged.
- Every exercise mode now exposes “I don’t know the answer” immediately and reveals the answer without accidentally graduating a Learn Card. After any rejected answer, “My answer was correct” reverses only that rejection’s error penalty and completes from the pre-answer engine state. Learn, Quick Choice, Practice Builder, Chaos, and Today all follow the same learner-controlled recovery pattern.

Symbol Lessons use a mouse/pen/touch handwriting canvas with reference comparison in Learn, Today and configurable practice, while legacy all-kana Lessons are recognized automatically.
- Handwriting accepts any number of separate strokes without failing when the pen, finger or mouse is lifted. A local normalized shape comparison reports similarity, keeps the completed drawing beside the correct glyph, supports retry, and lets the learner correct both false rejection and false acceptance before the result is saved.

## Browser-dependent fallbacks

- In the browser build, manual Lesson export remains available; desktop maintains `Vocabulary Trainer Data/lessons` automatically.
- System voices, MediaRecorder/microphone, PWA installation, and persistent-storage grants depend on browser/device support.
- Google Images requires a network connection. Installation of the shared translation package requires a network connection, but all canonical translation directions and existing local Lessons work offline afterward; the browser build retains manual translation entry/import.

## Known gaps / blockers

- No product blocker is currently known. Android APK remains future packaging work.
- The Windows EXE is not code-signed, so Windows SmartScreen may show an unknown-publisher warning. The single-file portable EXE extracts its Electron/app payload on every launch; use the unpacked executable for meaningful startup-performance measurements.
- Video is not a Card media type in the product specification or current domain model. Lesson files include every media type the application currently supports: images, custom audio, and generated audio.
